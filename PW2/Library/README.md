# Catálogo de livros (PHP + Open Library)

## Requisitos
- PHP 8.0+ com a extensão **cURL**
- Acesso à internet

## Executar
```bash
cd biblioteca
php -S localhost:8000
```
Abra http://localhost:8000

## Antes de publicar
Em `index.php`, troque o e-mail na constante `AGENTE_USUARIO`. A Open Library pede que
quem usa a API se identifique.
